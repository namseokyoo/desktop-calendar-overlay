# Codex Goal Prompt — v0.95.0 Official OAuth Client Transition

## Mission

Transition Desktop Calendar Overlay from developer/tester BYO OAuth JSON as the default path to an app-owned official OAuth client path, without committing OAuth secrets and without claiming Google verification approval.

## Branch/tag

- Work branch: `release/v0.95.0-official-oauth-client`
- Target tag: hold until Windows smoke, release ZIP audit, and Google OAuth console setup are complete.

## Scope

1. Add an official OAuth client provider that can load an app-owned installed-app OAuth client JSON from release/deployment-controlled locations.
2. Keep BYO local JSON only as a developer fallback when the official client JSON is absent.
3. Prefer official client provider over local JSON provider when both are present.
4. Rename/adjust availability language from `FutureOfficial` to actual `Official` readiness.
5. Update Settings/status text to make official OAuth the default public path and local JSON a developer fallback.
6. Add tests for provider priority and official availability state.
7. Update privacy/OAuth docs, QA checklist, release notes, and execution report.
8. Ensure release artifact hygiene still forbids accidentally committing or packaging unreviewed secrets.

## Out of scope

- Do not create a Google Cloud OAuth client through this repo task.
- Do not commit real `client_id` / `client_secret` / downloaded OAuth JSON.
- Do not claim OAuth verification approval.
- Do not remove the local JSON fallback until official OAuth is verified on Windows.

## Expected implementation shape

- `OfficialGoogleOAuthClientProvider` loads from safe non-committed paths, for example:
  - environment override path for CI/local validation,
  - app install directory file injected during release packaging,
  - optional local app-data override for manual smoke.
- `CompositeOAuthClientProvider` chooses the first available provider.
- `MainWindow` wires official provider first, local JSON fallback second.
- Tests verify official wins over local JSON when both are present.
